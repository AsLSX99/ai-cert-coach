# 备考协议：监考细则、判分回链、考前清单

> 日常三件事（学课 / 模考 / 弱项回链）与考前一周的执行手册。核心思想：**练习分数只用来找洞，不用来算命；考试事实只从 JSON 来，不从记忆来。**

## 一、学课循环（按 route）

1. `cert.py route <slug>` 出课程序列（role: orientation → core → …，required 优先）
2. 按 **领域权重 × 诊断得分率** 排优先级，权重高且分低的先学
3. 一课四步：读 `lessons/<dir>/docs` → 课内 quiz 全对 → 用自己的话写 3 句要点 → 标完成
4. 课的 `domains` 字段标它补哪个领域——**学完在计划里打勾，弱领域清单同步减一项**

## 二、模拟卷监考（核心协议）

### 出场顺序
```
cert.py ask <slug>/mock-01 <n>  → 用户作答（报选项）→ 全卷答完
  → cert.py reveal 逐题对 → 判分 → log 记分 → 出 mock-report
```

### 防剧透三规则
1. **整卷作答完成前不 reveal 任何一题**——包括"这题我拿不准，先看看"也不行，真实考试没有这个按钮
2. `ask` 只输出题面 + 选项（single 单选 / multiple 多选），`correct`、`explanation`、`references` 全封印
3. 用户中途要求跳题：允许标记后跳，但整卷结束统一回来看——不许边考边对

### 掐表
| 卷 | 官方限时 | 规则 |
|---|---|---|
| Claude diagnostic | 25 min | 到点停笔，没答的按错计 |
| Claude mock | 120 min | 整卷计时，中途不暂停 |
| MCPA 模拟 | 按卷面 `timeLimitMinutes` | 同上 |

到点停笔是硬规则——练的不只是知识还有节奏。

### 判分
- 逐题比 `correct` 数组：single 答对即得分；multiple **必须完全一致**（多选少选都不得分）
- 输出三个数：**原始分 %**（总）、**分领域得分率**、**用时/限时**
- 报分时的必带后缀：*"原始分，不等于官方量表分，不能预测官方结果"*（MCPA 则是"官方通过分未公布，只看趋势"）

## 三、弱项回链（判分后必做）

1. 拉出 0 分题和 multiple 部分对的题 → 它们的 `domain` + `objective`
2. 同领域错 ≥2 题 → 该领域标红，进"每日 15 分钟专项"，回 `references` 指的课重读
3. 每道错题的 `explanation` **用自己的话复述**进 mock-report——复述不出 = 解析没读懂，这条题下次模考必再考
4. 两套卷同领域都弱 → 升级为"回炉该领域全部 objectives"，计划里插一次专项日
5. 弱领域清单更新进 `cert-plan.md`，学课循环的优先级同步调

## 四、模考排期（倒排）

| 距考试 | 动作 |
|---|---|
| >14 天 | 诊断卷摸底 → 学课为主，每 7 天 1 套模考找洞 |
| 14-7 天 | 学课收尾，模考加密到每 3-4 天 1 套，弱领域专项 |
| 7-3 天 | **全真限时模考**（不暂停不查资料），只补弱项 |
| 前 1 天 | 不学新内容，过 `exam-eve.md` 一页纸 |
| 当天 | 按一页纸的考务须知走，出门前核对证件/设备/网络 |

MCPA 三套模拟卷的用法：mock-01 学课中期、mock-02 弱项补完后、mock-03 考前全真。Claude 轨只有一套 mock → **隔 7 天重考同一套**（题都记住了就换角度复述解析，重考只验节奏与领域均衡）。

## 五、考前一周清单（逐项打勾）

- [ ] 报考资格已核（Claude：合作企业邮箱/Partner 身份；MCPA：12 个月报考窗口）
- [ ] 考试事实已从 track JSON 抄进一页纸（题数/时长/费用/通过线/有效期 + lastVerified 日期）
- [ ] 最近一套全真模考原始分与领域拆分记录在案
- [ ] 弱领域 Top3 各完成一次专项回炉
- [ ] 错题 explanation 复述抽查 5 条全过
- [ ] 线上监考环境（摄像头、网络、证件、清场）按官方 FAQ 准备
- [ ] 费用/退改政策在官方页面再确认一次（政策会变）

## 六、时间异常处理

| 情况 | 处置 |
|---|---|
| 模考中断 | 记已答部分，改天整卷重考（半套卷的分数不入册） |
| 某领域连续两卷 0 题对 | 停模考，回该领域课 + practice 对应题，专项日后再考 |
| 考试日期变更 | 计划整体平移，studyPlans 14/28 天二选一重排 |
| 官方政策与本仓库不一致 | **以官方页面为准**，改计划并记变更日志 |
